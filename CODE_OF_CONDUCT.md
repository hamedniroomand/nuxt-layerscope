# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind and patient, assume good intent, and keep discussion about the work. Harassment,
personal attacks and discriminatory language are not welcome in issues, pull requests or any other
project space.

If someone's behavior makes you uncomfortable, email
[dev.hamedniroomand@gmail.com](mailto:dev.hamedniroomand@gmail.com). Reports are read by the
maintainer only and kept confidential. Anyone who breaks these rules may be warned, or banned from
the project.
