`layerscope init` names the keys that are set in the `layerscope` key of `nuxt.config`, and tells you to run `init --prepare` when the data is old. The suggestion for root code that uses a feature layer, under a preset with `root` as its base, says to move the code to root or remove the use. The root hint is short on each finding when the note gives the full text.
